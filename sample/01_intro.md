# AIによる自動生成仕様書

## 1. はじめに
これはAIがMarkdownとして出力した仕様書のサンプルです。AIは純粋なテキスト構造のみを生成し、レイアウトはTypstが担当します。

## 2. 機能要件
* ユーザー認証機能
* MarkdownからTypstへの自動変換
* PDFファイルの生成と保存

## 3. 必要な機能一覧

| 機能名 | 説明 | 優先度 |
| --- | --- | --- |
| 認証機能 | ユーザーのログイン/ログアウト | 高 |
| Markdown変換 | markdown-it-pyを用いたAST解析 | 高 |
| PDF出力 | Typstを用いた決定論的レイアウト | 高 |

## 4. 今後の課題
このように、**「データ」と「表現」を分離**することで、AIの確率的な揺らぎによるレイアウト崩れを防ぐことができます。
