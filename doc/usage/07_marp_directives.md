# Marpディレクティブ

Marp形式のスライドでよく使う3つのHTMLコメントディレクティブに対応しています。**そのページ以降、次の同種ディレクティブが出てくるまで**（ファイルをまたいでも）効き続けます。

```markdown
<!-- header: "第1部" -->
<!-- footer: "社外秘" -->
<!-- paginate: false -->
```

- `header:` / `footer:`: 空文字 `""` を指定するとクリアできます。値はクォート有無どちらでも構いません。
- `paginate:` : `true`/`false` のみ対応。
- `header:` はその時点で表示されているtitle（front-matterのtitle、または文書全体のtitle）より優先してヘッダーに表示されます。
- 上記以外のディレクティブや通常のHTMLタグ（`<br>` 等）は警告を出すだけで、ビルドは継続します。
