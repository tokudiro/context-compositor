# Marpディレクティブ

Marp形式のスライドでよく使う3つのHTMLコメントディレクティブ（`header`/`footer`/`paginate`）は認識しますが、**値は反映しません**（読み捨てます）。Marp原稿をそのまま`chapters`に流し込んでも、ビルドが失敗したり不要な警告が大量に出たりしないための措置です。

```markdown
<!-- header: "第1部" -->
<!-- footer: "社外秘" -->
<!-- paginate: false -->
```

これらを画面に反映したい場合は、独自テンプレート（「独自テンプレートを使う」の章）で対応する仕組みを自分で用意してください。ページ上部・下部への表示は、いったん実装を試みましたが、章の並べ替えに対して安全でない（並べ替えると意図しないヘッダーが別の章に混入しうる）ことが分かり撤回しています。

上記以外のディレクティブや通常のHTMLタグ（`<br>` 等）は、従来どおり警告を出すだけで、ビルドは継続します。
